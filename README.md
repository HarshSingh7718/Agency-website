# Rapidgrodigital Website

Rapidgrodigital Website using the original theme CSS, WebGL cursor-reactive hero smoke, marquees, magnetic buttons, and scroll reveals.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Build

```bash
npm run build
npm run preview
```

## Stack

- Vite
- Original theme CSS (`theme.css`, `responsive.css`, `sections-v2.css`)
- `hero-smoke.js` — WebGL cursor-interactive hero background
- `custom.js` — magnetic CTAs, marquees, counters, mobile nav, back-to-top
- Fonts: Urbanist + Instrument Serif + Great Vibes
- Icons: Iconify
